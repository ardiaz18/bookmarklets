# One Look SEO Audit

Auditoría SEO on-page rápida en un solo clic. Muestra un informe visual directamente sobre la página.

## Qué muestra

- **Meta**: title, description, robots, canonical
- **Encabezados**: conteo de H1, H2, H3
- **Enlaces**: internos, externos, nofollow
- **Imágenes**: cantidad sin atributo `alt`
- **Hreflangs**: listado completo
- **PageSpeed**: puntuación de rendimiento vía API de PageSpeed Insights (requiere API key configurada en el código)

## Uso

1. Navega a la URL que quieras auditar
2. Haz clic en el bookmarklet
3. Se abre un modal con el informe completo
