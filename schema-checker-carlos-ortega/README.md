# Schema Checker

Extrae, visualiza y valida el Schema JSON-LD de cualquier página. Abre los resultados en una ventana nueva con herramientas integradas.

## Qué hace

- Detecta todos los bloques JSON-LD incluyendo `@graph`
- Muestra el JSON formateado por cada `@type`
- Botón para copiar al portapapeles
- Enlaces directos a validadores: Schema.org y Google Rich Results Test
- Enlace a la documentación de Schema.org para cada tipo

## Uso

1. Navega a cualquier URL
2. Haz clic en el bookmarklet
3. Se abre una pestaña nueva con todos los schemas detectados
