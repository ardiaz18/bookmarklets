# SEO Keyword Inference Box

Analiza el contenido de una página y sugiere keywords relevantes basándose en el texto visible, encabezados, title, meta description y URLs internas.

## Qué hace

- Extrae texto del body, headings (H1-H3), title, meta description y anchors internos
- Normaliza y tokeniza el contenido (elimina stopwords en español)
- Genera n-gramas (1 a 4 palabras) ponderados por frecuencia y ubicación
- Muestra las keywords inferidas ordenadas por relevancia en un panel flotante

## Uso

1. Navega a la URL que quieras analizar
2. Haz clic en el bookmarklet
3. Aparece un cuadro con las keywords sugeridas, listas para copiar

## Instalación

Crea un nuevo marcador y pega como URL el contenido de `bookmarklet.js`.
