# Bookmarklets SEO

Colección de bookmarklets para análisis SEO, auditorías técnicas y scraping de SERPs. Úsalos directamente desde la barra de marcadores del navegador.

## Instalación

Para cualquier bookmarklet: abre la carpeta correspondiente, copia el contenido de `bookmarklet.js` y pégalo como URL de un nuevo marcador en tu navegador.

## Bookmarklets incluidos

| Bookmarklet | Descripción | Autor |
|---|---|---|
| [extract-schema](extract-schema/) | Extrae y lista los `@type` de todos los bloques JSON-LD de la página | Alicia Ruiz |
| [one-look-seo-audit](one-look-seo-audit/) | Auditoría SEO on-page: meta tags, encabezados, enlaces, imágenes, hreflangs y PageSpeed | Alicia Ruiz |
| [one-look-technical-seo](one-look-technical-seo/) | Análisis técnico detallado: headings completos y listado de enlaces internos/externos | Alicia Ruiz |
| [schema-checker-carlos-ortega](schema-checker-carlos-ortega/) | Extrae, visualiza y valida Schema JSON-LD con enlaces a validadores y documentación | Carlos Ortega |
| [search-scraping](search-scraping/) | Scraper de la primera página de Google con detección de AI Overview y export TSV | Alicia Ruiz |
| [seo-kw-inference-box](seo-kw-inference-box/) | Infiere keywords relevantes a partir del contenido visible de la página | Alicia Ruiz |
| [goto-recover](goto-recover/) | Resuelve las URLs reales detrás de los enlaces /goto?url= de Google Search | Natzir Turrado |
| [gsc-full-render](gsc-full-render/) | Reconstruye la página completa desde el HTML renderizado por Google en URL Inspection de GSC | Natzir Turrado |
