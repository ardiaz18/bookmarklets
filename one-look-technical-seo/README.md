# One Look Technical SEO

Análisis técnico SEO detallado de una página. Versión más profunda del audit, orientada a aspectos técnicos.

## Qué muestra

- **Encabezados**: texto completo de cada H1 y H2
- **Enlaces**: listado completo de internos y externos con sus URLs y anchor text
- **Análisis DOM**: usa XPath para recorrer el documento

## Uso

1. Navega a la URL que quieras analizar
2. Haz clic en el bookmarklet
3. Se muestra una tabla detallada con los datos técnicos

## Instalación

Crea un nuevo marcador y pega como URL el contenido de `bookmarklet.js`.
